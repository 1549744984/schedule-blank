安卓怎么装
  1. 点右边「安装证书」，下载 schedule-ca.crt
  2. 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书（不要选「VPN 和应用证书」）
  3. 用 https 地址重开本页，三项全绿后浏览器菜单「添加到主屏幕」
iPhone / iPad 怎么装
  1. 用 Safari 打开本页，点「安装证书」，允许下载描述文件
  2. 设置 → 通用 → VPN 与设备管理 → 安装该描述文件
  3. 设置 → 通用 → 关于本机 → 证书信任设置 → 打开对 Schedule Local CA 的完全信任
  4. 用 https 地址重开本页，「添加到主屏幕」
夸克里怎么固定到桌面
  1. 夸克没有「添加到主屏幕」（这是夸克自身限制，不是证书问题）
  2. 用底线菜单「收藏」把本页存起来，再从「收藏 / 书签」进
  3. 想放到手机桌面：夸克菜单里找「添加到桌面」，没有该项就用系统「快捷方式」类工具；也可以先用系统浏览器装一次 PWA，之后日常仍用夸克打开
