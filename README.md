# 日程表 · 白板版

一个纯本地的日程本：**数据是 Markdown 文件，程序只负责把它画出来**。没有账号、没有云、没有数据库。

月 / 周 / 日三个视图 + 便签 + 手机访问 + 自动备份。零第三方依赖，只用 Python 标准库。

> 这份是**白板版**：示例数据是编的，可以直接改成自己的。原版里带私人日程的仓库不在这里。

---

## 一、三步跑起来

**准备**：电脑装了 Python 3.10 或更新（`python --version` 能打出版本号就行）。Windows / macOS / Linux 都可以。

```bash
# 1. 下载（或用 git clone）
git clone <这个仓库地址>
cd 日程表-白板版

# 2. 启动
python server.py

# 3. 打开浏览器
#    http://127.0.0.1:8770
```

就这样。**不用 pip install，没有任何依赖。**

> 端口被占了？`set SCHEDULE_PORT=8780`（Windows）/ `export SCHEDULE_PORT=8780`（macOS·Linux）再启动。

## 二、三种用法

| 用法 | 怎么开 | 适合 |
|---|---|---|
| **浏览器** | 双击 `启动.vbs`（Windows）或 `python server.py`，再开 `127.0.0.1:8770` | 日常，最稳 |
| **桌面窗** | `pip install pywebview` 后 `python desktop/schedule_app.py` | 想要一个独立窗口、没有地址栏 |
| **手机** | 见下面第五节 | 出门前看一眼今天 |

浏览器版是主体，桌面窗和手机都是它的外壳。

## 三、数据放哪、怎么写

```
数据/
  日程/
    2026/
      2026-11-02.md      ← 一天一个文件
    2026-11.md           ← 月目标
    2026-W45.md          ← 周重点
  便签/
    收件箱/
      随便起名.md
```

**一天的格式**（照着改就行，`<!-- AUTO:... -->` 那几行是程序写回用的，别删）：

```markdown
---
date: 2026-11-02
type: 日计划
tags: [日程]
---

## 时间块

<!-- AUTO:events:start -->
- 08:30-10:05 高等数学 @教学楼A-301 #课程
- 16:00-17:00 ! 提交实验报告 @线上 #作业
- 全天 值日 @教室
<!-- AUTO:events:end -->

## 待办

<!-- AUTO:todos:start -->
- [ ] 交实验报告
- [x] 打印讲稿
<!-- AUTO:todos:end -->

## 备注

随便写，程序不解析这块。
```

三条规则：

1. **时间**：`HH:MM-HH:MM`，24 小时制、两位补零。没有时间的写 `全天`。
2. **地点**：`@` 开头，一直到行尾的 `#` 或结束，**可以带空格**（`@东盟 G-4012`）。
3. **重点**：标题前加 `! `（感叹号+空格）。**标签**：`#` 开头。

地点后面不能再写别的字；地点里不能有 `#`（`3#楼` 会被截成 `3`，写成 `3号楼`）。

## 四、界面上有什么

- **月**：一天一格。有日程的格子实、空的格子透（露出背景照片）。过去的日子整体退一档，上下个月的格子是中性灰。
  一格放不下时，底部出现 `…`，鼠标停上去能看到还剩几条。今天那格是橙色边框。
- **周 / 日**：左边时间轴，每小时一道短刻线，8 / 12 / 18 点三道深色分界。事件按时长画成块，重叠自动分左右。
- **便签**：左边分类、中间列表、右边直接写，停 0.8 秒自动保存。
- **页头徽章**：`页面 vX ｜ 服务 vY`，两个数字一样就是同版本；不一样会出红点并提示重启。

## 五、手机访问（同一个 WiFi）

1. 电脑上启动服务，点页头「**手机连接**」，弹层里会显示一个 `http://<电脑IP>:8770` 的地址。
2. 手机浏览器打开那个地址。
3. 想更像 App：手机浏览器菜单里选「**添加到主屏幕**」。

**HTTPS（可选，为了手机端离线缓存）**：

```bash
python tools/setup_https.py
```

会生成一个自签根证书 `certs/ca.crt`。手机上装这个根证书（电脑上开 `http://<电脑IP>:8770/schedule-ca.crt` 下载），
然后访问 `https://<电脑IP>:8771`。证书里已经把**本机所有 IP + 主机名 + localhost** 都写进去了，换 WiFi 不用重签。

> 电脑 IP 会变（尤其是校园网/公司网）。变了就在「手机连接」里看一眼新地址，那是实时检测的。

## 六、备份

两层，都在本地：

```bash
python tools/backup_schedule.py            # 手动跑一次
python tools/backup_schedule.py --dry-run  # 只看会备份什么
```

- **滚动副本**：每次保存前，把旧内容复制到 `备份/_最近一次/`，同名覆盖。改错了当场能捞回上一次。
- **每日快照**：`备份/daily/日程-YYYY-MM-DD.zip`，同一天重复跑只留一份，保留 30 天；每月 1 号另存月度包，保留 12 个月。

想每天自动跑，把它加进系统定时任务（Windows 任务计划 / macOS launchd / Linux cron）即可。

## 八、常见问题

**改完代码没生效？** 前端（css/js）关掉窗口重开就生效；`server.py` 必须重启进程。

**端口被占？** 换 `SCHEDULE_PORT`。桌面窗会自己找空闲端口。

**能同步到手机吗？** 同一个 WiFi 直接访问电脑，数据只有一份，不存在同步问题。出门在外不行——这是本地程序，不上云。

**数据会不会丢？** 数据就是 md 文件，用任何编辑器、任何网盘都能备份。程序另有上面那两层自动备份。

**能多人用吗？** 不能，也没打算做。这是单人本地工具。
